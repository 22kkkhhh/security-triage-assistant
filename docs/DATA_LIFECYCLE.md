# 数据生命周期定位

案件工作台提供一个基于现有案件事实的生命周期投影，用于帮助分析员定位当前证据涉及的数据处理阶段：

`采集 / 生成 → 存储 → 使用 / 查询 → 加工 / 处理 → 共享 / 传输 → 导出 → 归档 → 删除 / 销毁`

## 判断边界

- **已观测**：案件事实、时间线或证据中存在可回链的直接依据。
- **可能涉及**：已有相关上下文，但缺少该阶段的直接操作记录。
- **未发现**：当前已接入事实已检查，未发现该阶段事件。
- **信息不足**：当前没有足够的该阶段来源，不能据此判断“未发生”。

每个阶段最多展示三条依据，可回到证据或调查时间线。该投影不替代人工研判，不自动推断数据泄露、违法或责任归属，也不会扩大案件原有可见数据范围。

## 实现原则

生命周期由 `CaseDraft`、规则生成的 `Evidence` 与 `TimelineEvent` 即时派生，不新增数据库表或平行事实模型。新增数据源接入后，只需将标准化事实映射到现有字段即可逐步提高覆盖率。
